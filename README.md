# بازی خشت

یک بازی ساده شبیه Flappy Bird با **۸ مرحله** و سختی افزایشی، ساخته‌شده با **Kivy**.

## اجرا

```bash
pip install -r requirements.txt
python main.py
```

## کنترل

| عمل | کلید |
|-----|------|
| پرش | لمس صفحه یا کلیک موس |
| بازگشت به منو | دکمه «منو» |
| خروج | دکمه «خروج» در منو |

## مراحل

1. **آسان** — موانع آبی آرام  
2. **متوسط** — کمی سریع‌تر  
3. **سخت** — موانع سبز متحرک شروع می‌شوند  
4. **خیلی سخت** — شتاب موانع  
5. **روانی** — حرکت عمودی زیاد  
6. **فوق‌روانی** — ترکیب سخت‌تر  
7. **دیدار با قبر** — موانع قرمز مرگبار  
8. **بهشت** — سخت‌ترین حالت  

## ساختار پروژه

```
khesht/
├── main.py          # نقطه شروع
├── config.py        # تنظیمات مراحل
├── entities.py      # بازیکن و موانع
├── menu_screen.py   # منوی انتخاب مرحله
├── game_screen.py   # منطق بازی
├── requirements.txt
└── assets/
    └── splash.png
```

## نکات

- امتیاز = تعداد موانعی که از آن‌ها رد شده‌ای  
- بعد از Game Over می‌توانی «دوباره» بزنی یا به منو برگردی  
- سختی مراحل طوری تنظیم شده که قابل‌بازی باشد (نه غیرممکن)


## ساخت APK
این پروژه برای ساخت APK با GitHub Actions آماده شده است. فایل `.github/workflows/build-apk.yml` را نگه دار و پروژه را در ریشه Repository قرار بده. سپس از Actions > Build APK > Run workflow اجرا کن. طبق مستندات Buildozer، خروجی build در پوشه `bin/` ساخته می‌شود. 


## فارسی و RTL
- متن‌های فارسی با `arabic-reshaper==3.0.0` و `python-bidi==0.4.2` قبل از نمایش شکل‌دهی می‌شوند.
- فونت اصلی متن فارسی `NotoSansArabic` است چون فرم‌های ارائه‌شده حروف عربی/فارسی را دارد.
- `assets/fonts/Suls.ttf` نیز در پروژه نگه داشته شده است؛ این فونت برای حروف پایه فارسی مناسب است اما برای روش shaping مورد استفاده در Kivy فرم‌های ارائه‌شده عربی را ندارد، بنابراین برای جلوگیری از مربع شدن حروف به‌عنوان فونت اصلی استفاده نشده است.

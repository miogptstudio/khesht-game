# بازی خشت

یک بازی ساده شبیه Flappy Bird با **۸ مرحله** و سختی افزایشی، ساخته‌شده با **Kivy**.

## اجرا

```bash
pip install -r requirements.txt
python main.py
```

## کنترل

| عمل | کلید |
|-----|------|
| پرش | لمس صفحه یا کلیک موس |
| بازگشت به منو | دکمه «منو» |
| خروج | دکمه «خروج» در منو |

## مراحل

1. **آسان** — موانع آبی آرام  
2. **متوسط** — کمی سریع‌تر  
3. **سخت** — موانع سبز متحرک شروع می‌شوند  
4. **خیلی سخت** — شتاب موانع  
5. **روانی** — حرکت عمودی زیاد  
6. **فوق‌روانی** — ترکیب سخت‌تر  
7. **دیدار با قبر** — موانع قرمز مرگبار  
8. **بهشت** — سخت‌ترین حالت  

## ساختار پروژه

```
khesht/
├── main.py          # نقطه شروع
├── config.py        # تنظیمات مراحل
├── entities.py      # بازیکن و موانع
├── menu_screen.py   # منوی انتخاب مرحله
├── game_screen.py   # منطق بازی
├── requirements.txt
└── assets/
    └── splash.png
```

## نکات

- امتیاز = تعداد موانعی که از آن‌ها رد شده‌ای  
- بعد از Game Over می‌توانی «دوباره» بزنی یا به منو برگردی  
- سختی مراحل طوری تنظیم شده که قابل‌بازی باشد (نه غیرممکن)
